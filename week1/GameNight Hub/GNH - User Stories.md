# User Stories GameNight Hub

Als \[type gebruiker] wil ik \[actie], zodat \[doel]

1. Als nieuwe gebruiker wil ik een account registeren, zodat ik mij later kan inloggen om mee te spelen.
2. Als bestaande gebruiker wil ik mij kunnen inloggen en uitloggen, zodat ik de applicatie kan gebruiken.
3. Als gebruiker wil ik andere profielen kunnen zien, zodat ik deze mensen kan toewijzen aan mijn game-avonden en hun punten in de leaderboard kan zetten.
4. Als gebruiker wil ik aanpassingen kunnen maken in mijn account, zodat mijn account er persoonlijker uit ziet. Ik wil zowel een profielfoto uploaden, als de achtergrondkleur van mijn profiel aanpassen, als de kleur van mijn naam die op de leaderboard verschijnt.
5. Als gebruiker wil ik spellen kunnen toevoegen aan mijn spellencollectie, zodat ik die later met vrienden kan spelen. Een spel in mijn spellencollectie heeft een titel en het aantal spelers dat dit spel gelijktijdig kan spelen.
6. Als gebruiker wil ik game-avonden kunnen organiseren, zodat ik leuke spellen kan spelen. Een game-avond bestaat uit een datum, een locatie en een lijst van deelnemers.
7. Als organisator van een game-avond wil ik kunnen registreren wie er gewonnen heeft en hoeveel punten elke deelnemer behaalde, zodat deze op de leaderboard kunnen staan.
8. Als gebruiker wil ik de leaderboard kunnen zien, zodat ik weet hoe goed ik in een bepaald spel ben en of ik aan de leiding sta.
